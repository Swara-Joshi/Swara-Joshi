## 🔥 Featured Projects

### 📈 Intelligent Stock Analysis System  
- Built a financial sentiment intelligence system that analyzes market-moving news and links it to real stock price reactions using a hybrid labeling method that achieves **85–90% validated accuracy**.  
- Fine-tuned **Mistral-7B** with LoRA adapters + **4-bit quantization**, enabling low-resource training optimized for financial language.  
- Designed a robust evaluation pipeline (precision, recall, F1, MAPE, directional accuracy) to validate prediction consistency across **21+ financial instruments**.

---

### 💡 AI-Powered Investment Intelligence Platform with Agentic Orchestration  
- Engineered an automated due-diligence platform for **Forbes AI 50** companies using **Apache Airflow**, orchestrating parallel web scraping, ETL pipelines, and incremental change detection (content hashing).  
- Processes **50+ companies daily**, storing data on AWS S3 with scalable refresh routines.  
- Built a dual-pipeline LLM reporting system combining:  
  - **RAG** (ChromaDB with 294+ chunks)  
  - **Structured extraction** (Pydantic + Instructor)  
  Achieved a **25% accuracy improvement** through strict evaluation & schema validation.  
- Developed a production-grade agentic architecture using **LangGraph, MCP, ReAct**, and containerized microservices (FastAPI, Streamlit, MCP server), including a **Human-in-the-Loop** workflow.

---

### 🎬 YT Navigator  
- Built a Generative AI system that indexes **100+ YouTube transcripts** using vector embeddings, LangGraph, and LangChain agents.  
- Achieved **95% faster semantic retrieval** with **3-second timestamp precision**.  
- Implemented hybrid search using **PGVector semantic search + BM25 keyword matching** via a dual-agent architecture with ReAct-based reasoning.  
- Improved retrieval accuracy by **25%** through optimized tokenization and chunking strategies.
